# bot

Проект для управления локальным компьютером через Telegram-бота.

Основной рабочий код находится в папке remote_access_tg_bot.

## Что умеет бот

- Показать внешний IP адрес устройства
- Показать краткие характеристики системы
- Сделать скриншот экрана
- Сделать фото с веб-камеры
- Показать локальное сообщение на экране
- Показать окно ввода и отправить ответ в Telegram
- Установить обои из изображения, отправленного в чат

Важно: используйте проект только на своих устройствах и с явного согласия владельца.

## Структура проекта

- main.py: минимальная точка входа-заглушка
- semen.py: отдельный учебный скрипт с вычислением функции
- pyproject.toml: метаданные и зависимости Python-проекта
- remote_access_tg_bot/
  - bot.py: основной Telegram-бот и все обработчики команд
  - config.py: чтение и валидация переменных окружения
  - .env.example: пример файла с токеном и chat id
  - README.md: короткая локальная инструкция по подпроекту

Примечание: папка remote_access_tg_bot содержит собственный .git, то есть это вложенный git-репозиторий.

## Как это работает

1. При старте bot.py загружает настройки из переменных окружения TG_BOT_TOKEN и TG_CHAT_ID.
2. Выполняется проверка конфигурации через validate_config().
3. Создаётся экземпляр TeleBot и регистрируются обработчики:
	- /start, /help: показывает клавиатуру с действиями
	- IP Address🌎: запрос к jsonip.com и отправка IP
	- Specifications ⚙: информация о платформе через модуль platform
	- Screenshot 👀: снимок экрана через pyautogui
	- WebCam 📷: кадр с камеры через OpenCV
	- Message ✉: локальное alert-окно
	- Input 📩: локальный prompt с отправкой ответа в чат
	- Wallpaper 🖼: принимает фото и ставит его как обои Windows
4. После инициализации запускается bot.polling(none_stop=True) и бот постоянно слушает сообщения.

## Требования

- Windows (функция смены обоев использует Windows API)
- Python 3.12+
- Доступ к интернету для Telegram API и получения IP
- Доступ к экрану и устройствам (камера, GUI)

## Установка

Из корня репозитория:

1. Создайте и активируйте виртуальное окружение (если нужно).
2. Установите зависимости:

	pip install -e .

3. Создайте файл remote_access_tg_bot/.env по образцу remote_access_tg_bot/.env.example и заполните:

	TG_BOT_TOKEN=ваш_токен_бота
	TG_CHAT_ID=ваш_chat_id

## Запуск

Перейдите в папку remote_access_tg_bot и выполните:

python bot.py

При успешном старте бот отправляет сообщение Bot online в чат, указанный в TG_CHAT_ID.

## Кратко о зависимостях

- pytelegrambotapi: работа с Telegram Bot API
- requests: HTTP-запросы
- pyautogui: скриншоты и GUI-диалоги
- opencv-python: захват изображения с веб-камеры
- pydantic и pydantic-settings: подготовлены в зависимостях проекта
- sqlalchemy, aiosqlite, alembic: подготовлены в зависимостях проекта

## Ограничения и риски

- Часть функций зависит от активной графической сессии пользователя (экран не должен быть недоступен).
- Антивирус и политики ОС могут блокировать действия pyautogui или работу с камерой.
- В текущей реализации нет ограничений по пользователям внутри обработчиков, поэтому доступ определяется секретностью токена и chat id.
